# 持仓板块观察审阅说明

此功能仅在独立公开版实现，尚未上传或部署。没有访问个人版持仓或改变个人版服务。

## 审阅路径

1. 打开本机预览，点击“体验虚构示例”，找到“持仓板块观察”。示例关联人为设置，不从名称推断。
2. 点击“管理板块关联”，选择持仓、选择参考板块并勾选核对。未核对的选择不生效，空选后确认表示明确无合适参考。
3. 返回首页：看技术位置、相对沪深300的共同日期窗口、情绪证据缺失。已有个人规则触发时，优先提示相应核对动作。
4. 展开详情：查看相关产品、按币种的关联金额、均线/RSI/MACD/量能和个人规则证据。关联金额不是底层行业仓位，跨板块不可相加。
5. 编辑并放弃、导出完整备份、清除、恢复、主动本机保存后刷新，确认关联保留；纯布局没有板块字段。

## 当前覆盖与限制

首批固定半导体、医疗、新能源车三个ETF代理，其他板块保持未知。没有自动基金穿透、自动行业识别、新闻情绪、资金流、目标价或买卖建议。技术指标是历史价格/成交量计算；与个人规则结合提供观察和核对事项，不能解释为个性化交易决策。

本次本机采集时间为2026-10-27T03:39:21.467Z，三个代理各250个样本，最新完整收盘日2026-10-26。浏览器不向行情方发送关联或持仓，只读取所有用户相同的静态包。数据包保持Git忽略；公开再分发许可未确认，不应据此直接发布。

相对市场只在双方21个共同日期足够时显示，摘要始终标窗口日期；基准采集失败、网络读取失败或共同窗口超过7日分别提示。抓取时间不替代价格时间。MACD初始化采用首样本EMA，数值可能与其他软件不同。
