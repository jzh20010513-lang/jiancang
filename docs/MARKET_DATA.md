# 固定公共行情包（本机审阅）

六个固定参考项由 `src/market-catalog.mjs` 定义。浏览器只读取同源 `/market-data.json`；关联、隐藏、排序和持仓内容不改变第三方请求。运营脚本不接收持仓代码、symbol、自定义 URL 或任何参数，不读取个人版文件。

## 手动刷新与离线构建

在本项目目录运行 `node scripts/refresh-market.mjs`。需要宿主 Node.js 和 curl，沿用宿主已有代理；每项请求最多 20 秒、响应最多 1 MB，总共固定六项。请求不携带个人信息、cookie、账户或持仓。错误日志不打印响应正文、请求头和代理配置。采用临时文件后原子重命名，只写本项目 `public/market-data.json`。

`node scripts/prepare-market.mjs` 不访问网络。已有文件经固定公共白名单校验后写回清洗包；私有字段、非法结构或任意来源会阻止构建并保留原文件，采集时间和价格日期不改变。不存在时生成包含全部六项、明确不可用的包。构建调用 prepare，不自动调用 refresh。行情文件是本地资料，应被 Git 忽略；不将行情原始响应、截图加入发布包。

本机静态预览使用构建后的文件，刷新应连续执行 `npm.cmd run market:refresh` 和 `npm.cmd run build`，然后在页面重新读取数据包。只运行采集脚本不会自动替换已经构建的站点文件。没有定时任务、浏览器轮询或线上部署。

顶层结构固定为 `{schemaVersion:1, generatedAt:ISO, mode:'public-snapshot', records:[...]}`。每条为 `{id, points:[{date:'YYYY-MM-DD',close:number}],quote:null,source:{label,url},status:'available'|'unavailable',error:null|string}`。`generatedAt` 是本次包生成时间，不表示每条旧数据成功重新采集；失败时 `error` 保留失败信息，`points` 只保留校验通过的历史价格与原始日期。`available` 表示存在有效日线点，并不保证最新、足够画曲线或足够计算涨跌。

## 来源和口径

腾讯财经 HTTPS 日线接口，CN/HK 路径 `appstock/app/fqkline/get`，US 路径 `appstock/app/usfqkline/get`。每条记录 `source.url` 包含固定白名单参数 `param=<providerKey>,day,,,250,qfq`。解析 JSON 或简单赋值包装，不执行 JavaScript。采用 `qfqday`（存在时）或 `day` 的第三列 close；忽略实时 qt 字段。前复权行情可因上游修订而变化，不是总回报序列。

接口实测会在日线末尾放入当天盘中 OHLC，因此按市场当地日期过滤尚未完成的交易日：CN 在上海时间 16:00 前、HK 在香港时间 17:00 前、US 在纽约时间 17:00 前排除当天。这个保守时间还留出收盘后更新缓冲；不承诺交易所最终结算值。不存在当天点时不补造。日期必须真实且严格递增；非正数、非数值、重复日期、倒序和空系列均拒绝。UI 的相邻日变动只来自最后两个有效日线 close，不混入实时价格。GLD 是美元/份的黄金 ETF，不能解释为银行人民币金价、积存金或账户收益。

## 发布边界与验证

公开接口可读取不等于已取得行情再分发授权。上游数据许可、再分发范围、商业使用条件和接口服务承诺尚未确认；本适配器与实际快照仅供本机审阅，不宣称可用于生产公开发布。发布前应另行取得适当授权并复核来源条款。

`node --test tests/market-data.test.mjs` 覆盖固定目录、包装解析、异常日期和价格、失败保留、固定 URL 以及盘中日线过滤。2026-10-27 实测 6/6 通过；同时项目当时全部 88 个单元测试通过。离线测试只证明规则，不证明未来接口可达性。
