## 体验路径
打开 `http://127.0.0.1:4318`，体验虚构持仓；市场卡片使用公共收盘快照，二者来源分别说明。首页顺序为相关市场、资产概况、前三项体检和详细明细；配置对照、用钱详情、剩余体检和上次快照可展开访问。

包生成时间不冒充价格日期，旧数据/失败/历史不足分别说明。参考项不是实际持仓收益，GLD不是人民币金价或银行报价。未确认上游再分发授权，因此不作为生产公开发布版本。行情文件与产物仅留在本机并被Git忽略，公开仓库可重建明确无数据的安全降级状态。

## 重开与刷新
双击工程根目录“打开审阅版.cmd”或执行 `npm.cmd run preview`。行情更新需执行 `npm.cmd run market:refresh`，成功或保留旧快照后再执行 `npm.cmd run build`；浏览器“重新读取数据包”只读取已构建的同源文件，不直接调用第三方源，也不会自动采集或上传持仓。
