## 已实现

技术面从一个收盘价格改为趋势、动能、量能三项事实与一句综合解释。原始价格、均线、RSI、MACD数值仍在详情保留。

- 趋势同时对照MA20/60位置及其相对5个样本前的方向；位置与方向冲突时显示分歧。均线、MACD及成交量的含义提供折叠白话说明。
- MACD至少61条样本才判连续两期变化，金叉、死叉与DIF上穿/下穿零轴分别记录。负柱缩短只说明动能变化，不宣称趋势反转或见底。
- 量能说明本次成交量相对此前20个样本均量的倍数和价格涨跌。未知量、零均量不计算；不推断主力或净流入。
- 日线与周线边界明确：本轮没有长期周线确认。加载、过期、来源失败和刷新失败均不生成当前技术结论；旧原始数值保留来源日期用于核对。
- 个人建议和技术解释统一使用趋势状态，个人配置上限、资金期限等规则仍优先。市场行改称“市场对照”，解释百分点差值并明确不是基金收益；情绪仍不评分。
