# 本地审阅交付与验收说明

日期：2026-10-26。范围：独立静态 MVP，可在本机审阅；不是面向全部浏览器/金融平台的正式公开发行版。

## 审阅入口

本机预览 `http://127.0.0.1:4318`。独立工程根目录中的 `打开审阅版.cmd` 可在预览停止后重新启动。站点只服务该工程 `dist/`，监听 127.0.0.1，不调用个人版服务。

建议先用虚构示例看布局，再用合成截图检查识别和核对流程。所有开发、自动化和 OCR 评测使用合成数据；没有读取或复制个人真实持仓、截图、备份或运行数据。

浏览器下载会产生本机 Blob 读取和 Edge 内部下载面板资源。网络验收将这些设备内操作与 HTTP 网络分开记录；不把 Blob 当外发，也不忽略未知第三方 HTTP 请求。

完整流程记录中有 8 条 Tesseract 旧模型参数警告，输出为控制台 error 类型但文本以 `Warning: Parameter not found:` 开头。测试只对逐项列出的已知参数警告单独归档，不把它们计为应用异常；没有宣称控制台完全无警告。异常和警告均保存在本地报告。

## 独立审阅与修复

已完成独立代码审阅，并对以下问题补 RED→GREEN 或实际故障/时序验证：

- 保存失败选择会话使用时保留旧持久快照，不错误清除。
- 非法金额不变成确定金额或被静默清空，错误提示不重建表单吞掉输入。
- 聚合与明细共用筛选，布局保存成功后才应用，失败恢复旧布局。
- 金额显示直接格式化十进制字符串，避免大额浮点舍入。
- OCR 跨行币种冲突保持未知，非法千分位不去掉逗号冒充准确值。
- 识别取消/立即重试和图片解码以批次令牌隔离；解码中保留新输入，准备图片时不提前识别。

审阅者复核：无剩余已知重要问题。此结论不代替未测试浏览器、真实金融平台、真实设备和第三方许可的公开发行验收。

## 当前限制与发布前事项

1. 真实银行/券商版式没有认证。名称的完整行召回明显低于金额；必须逐行人工核对。
2. 只验证本机 Windows Edge。响应式宽度测试不是手机设备测试，Safari/Firefox/iOS/Android 尚未验收。
3. 首版不提供自动行情、汇率换算、收益曲线、历史收益率、云同步、负债/空头统计。
4. 原图不持久保存，结构化持仓和导出文件未加密。共享设备需自行管理访问权限。
5. 正式公开前由所有者选择应用许可证，复核模型及全部第三方声明，并在最终托管域名验证安全响应头。
6. 未创建远程仓库，未修改远程配置，未上传 GitHub，未部署到公共或私人云站点。

## 隔离与复现

工程由零创建，没有从个人工程复制源码、配置、Git历史或数据。仅复制了两份不含持仓的设计文档作为需求依据。个人版文件状态与任务开始时一致，本轮未在个人工程暂存、提交、重启或运行测试。

本工程执行顺序：`npm ci --ignore-scripts` → `npm run check` → `npm run preview`。素材和 OCR 基准的复现见 [OCR 评估](OCR_EVALUATION.md)。浏览器自动化使用临时配置，不复用用户日常浏览器资料。`artifacts/`、`dist/`、模型生成目录和依赖全部被 Git 忽略；测试截图和日志不进入源码提交或发布输入。

本地 Git 基线在自动化、构建、启动和浏览器检查完成后创建，消息为 `chore: initialize git repository`。后续完整功能应按项目要求独立提交。当前是待所有者审阅的本地交付，不执行自动合并或发布。
