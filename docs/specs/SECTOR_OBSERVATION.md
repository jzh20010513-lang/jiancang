# 持仓板块观察（本地审阅版）

用户已同意继续：先实现板块关联、技术证据、市场背景及可解释的观察建议；情绪没有可信证据时明确缺失。仅修改独立公开版，不上传、不部署、不接触个人版数据。

## 行为与边界

- 首批固定半导体、医疗、新能源车三个ETF观察代理。用户逐项选择并确认持仓关联，不按名称、代码或币种猜测。明确无参考与尚未核对分别计数。
- 首页按全部已导入持仓显示关联板块。金额按币种独立汇总，仅计已核对、非负、支持币种的行，称为“关联产品金额”，不等于行业敞口；跨板块金额可能重复，不计算行业仓位比例。
- 公共数据包统一下载到浏览器，再本地匹配。只允许固定同源 GET，无持仓参数、上传、云端AI或用户数据库。采集脚本仅接受固定白名单，无运行时自定义URL。
- 展示 MA20/60、RSI14、MACD12/26/9、20样本量比、近20样本区间变化和最大回撤。历史不足为空；量能不是情绪或资金流。明示ETF代理、样本、日期、参数。
- 相对沪深300：取双方最近21个相同日期收盘，比较区间涨跌幅差（百分点），不向前填补、不称持仓超额收益。
- 情绪栏保持“证据不足，暂不评分”。不把价格或放量包装成情绪、主力资金或新闻结论。
- 陈旧（超过7日）、失败、混合/缺失持仓日期、待核对行均显式标注。旧行情只保留原日期。
- 下一步提供观察条件、关联核对和已有个人规则触发项。个人规则只引用命中关联持仓的体检事实，不自动产生买卖、目标价或行业配置建议。
- 完整备份保留可选 sectorIds/sectorReview；旧备份默认未知；纯布局不含这些字段。编辑关联不滚动上次持仓快照。

## 验收

数学固定样本与缺失边界；严格数据包/备份校验；无数据不造指标；管理草稿、备份恢复、本机保存、清除、金额隐藏、三种宽度；网络请求仅固定静态资源；回归现有OCR和目标体检。公共数据再分发授权未确认，保持本地审阅。
