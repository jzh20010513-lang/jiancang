# 基金对应板块选择

用户要求持仓对应的板块可选，明确提出美股科技选项缺失。本轮在独立公开版本地实施，不上传、部署或读取个人版数据。

1. 将可选分类目录与公共ETF行情目录分开。保留既有三个ETF固定数据源；增加美股科技、港股科技、A股科技、人工智能、软件、互联网、医药、消费、能源、金融、制造、房地产、黄金、宽基、全球股票、债券、货币等常用选项。
2. 根据名称/代码的明确证据展示本地候选与依据、将相关选项优先放在前面。全球/QDII不等于美股科技，纳指100不等于纯科技。没有明确证据保持未推荐；用户可以直接确认自己的分类。
3. 支持自定义分类名，保存在持仓可选customSectorNames字段，内置sectorIds保持固定ID。内置与自定义合计最多3项，名称只作文本，不支持外部URL或可执行配置；可在备份恢复后继续编辑，纯布局不含分类。
4. 首页按已确认的内置/自定义分类生成关联产品汇总。没有行情代理的分类显示“已归类，专属行情未接入”，不生成技术/市场/情绪分数，也不误用沪深300作为美股科技基准。
5. 兼容旧备份，编辑关联不滚动上次快照；取消草稿和写入失败保持既有内容。测试使用匿名持仓；独立审查后本地提交。

验收包含美股科技选择、候选不自动确认、QDII不乱猜、自定义备份恢复、选择数量限制、旧三个行情数据包不变、无行情诚实空态，以及移动宽度和网络隐私。
