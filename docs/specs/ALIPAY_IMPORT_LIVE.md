# 支付宝导入与当天行情修正

用户反馈支付宝App截图名称/金额识别严重错误、缺乏基金板块归类，要求当天大盘信息。此轮先修复可复现的解析错误，不把合成测试当真实截图验收。浏览器连接未找到现有页面，不刷新或修改用户会话；原图不入仓库、不云端处理。

1. OCR使用版式坐标保留行顺序与金额列关系；文字回退解析识别持仓金额列、收益列、换行名称和独立金额行。多金额不明确时保持待补，禁止使用最后数字猜测。预处理只在内存，补充合成支付宝风格回归，所有候选仍需核对。
2. 本地基金分类建议优先固定代码，其次明确名称关键词；冲突/截断保持未知，不模糊补名。不把主题名当实际敞口。建议供用户确认，不覆盖手动确认关联；未覆盖板块明确提示。
3. 当天指数报价与历史曲线分开。固定四个A股公共指数，浏览器统一同源GET，不带持仓参数；仅本地公共数据代理，内存缓存，无用户数据库；60秒轮询、页面隐藏暂停。显示来源时间和过期状态，免费源延迟未知，不保证交易级实时。失败保留旧时间。
4. 分开提交：导入/分类修复和当天报价各自验证、提交。公开数据授权仍待核对，不发布、不上传。
