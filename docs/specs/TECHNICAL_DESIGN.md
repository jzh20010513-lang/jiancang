## 1. 架构决策

采用静态网页 + 浏览器本地 OCR + 人工核对 + 纯函数聚合 + 可选 IndexedDB 存储。没有业务后端、云端 OCR、登录或服务器持仓数据库。静态托管服务只提供公开程序、模型和示例资源。

建议新工程使用 TypeScript、轻量构建工具和 Web Worker；前端框架由实施者按维护成本选择，不因开源强制迁移个人版框架。OCR 引擎通过接口隔离；本文不指定未经验证的包版本、准确率或下载源。选型时再核对官方文档、模型与依赖许可证，并固定锁文件。

### 1.1 数据流

```text
静态站点 --公开程序/模型--> 浏览器
用户选择文件 --> 校验/解码/裁剪 --> OCR Worker
OCR 文本块 --> 字段候选与疑点 --> 核对草稿
核对草稿 --用户确认--> 当前快照 --> 聚合计算 --> 看板
当前快照/布局 --主动选择--> 本机 IndexedDB
当前快照/布局 --主动导出--> 用户设备上的 JSON 文件
```

业务数据没有向服务器或第三方发送的路径。文件名不进入请求、URL 或日志。模型下载与文件内容无关，使用固定公开路径。

### 1.2 模块划分

| 模块 | 输入/输出 | 禁止事项 |
| --- | --- | --- |
| image-input | File → 解码后的像素/裁剪区域 | 上传、保存原图、以文件名构建网络 URL |
| ocr-worker | 像素 → 文本块/位置/引擎置信度 | 联网推理、动态拉取第三方脚本 |
| adapters | 文本块 → 字段候选/冲突 | 将不确定数字默认为确定字段 |
| review | 候选 → 用户确认的草稿 | 自动覆盖当前快照 |
| domain | 确认快照 → 按币种统计 | 网络、DOM、隐式汇率或推断缺失金额 |
| storage | 用户确认应用的版本化快照/布局 ↔ IndexedDB | 原图、OCR 全文、调试输出入库 |
| dashboard | 聚合结果/布局 → UI | 拼接用户 HTML、修改底层数据口径 |
| transfer | schema 校验 ↔ 本地 JSON | 执行导入内容、接受远程资源字段 |

## 3. 文件与 OCR 处理

### 3.1 输入校验

按 PRD 限制文件个数、字节数及像素数。校验 MIME、文件头与实际解码结果；拒绝 SVG、HTML、PDF 和动图。先读取尺寸信息限制解码资源，再在受控任务中解码；校验无法可靠完成时拒绝文件，不无条件解码。

不生成完整图像的 Base64 日志，不把 File 存入状态持久化工具。用户裁剪在本地进行；OCR 使用去除元数据的像素副本，保留截图局部用于当前会话核对。

### 3.2 工作线程与取消

同一时刻默认一个 OCR Worker，逐图处理；长图按区域切块，块间适度重叠并保留坐标映射。用任务 ID 屏蔽已取消任务的迟到结果。取消/超时后终止 Worker、释放对象 URL、关闭位图、清空原文引用。垃圾回收和操作系统缓存不属于可保证的安全擦除。

建议单图 60 秒无完成则给出超时兜底，首次模型下载单独计时；阈值由设备实测调整。UI 主线程不执行 OCR 主计算，提供进度与可操作的取消按钮。

### 3.3 识别引擎抽象

```ts
interface OcrEngine {
  initialize(onProgress: (stage: string, ratio?: number) => void): Promise<void>;
  recognize(input: ImageBitmap, taskId: string): Promise<OcrBlock[]>;
  dispose(): Promise<void>;
}
interface OcrBlock {
  text: string;
  box: [number, number, number, number];
  confidence: number | null;
}
```

引擎置信度不是字段正确概率，跨引擎不能直接比较。所有导入结果都经过核对。金额、币种、日期的结构冲突即使分数高也标记为待处理。

### 3.4 版式适配

通用适配器保留表格候选，支持手动将区域映射到字段；首版不开放用户编写脚本。已验证版式适配器按标签、行列关系和坐标生成候选。对 O/0、负号、小数点、单位进行候选转换，保留原片段供核对，不静默纠错。

截图相同的哈希仅用于会话内重复文件提示，不自动删除。跨图重叠结合文本与区域识别；同名、同金额不证明是同一资产。用户决定保留/排除并可撤销草稿操作。

## 4. 数据模型与财务口径

以下为逻辑 schema；编码时以运行时校验器落实约束，不能仅靠 TypeScript 类型。

```ts
type DecimalString = string; // 十进制字符串，无科学计数法
type ConfirmedHolding = {
  id: string;                  // 本地随机 ID
  accountId: string;
  name: string;
  code: string | null;
  assetGroupId: string | null; // 用户确认才共享；不是同名自动聚合
  currency: string | null;
  marketValue: DecimalString | null;
  asOfDate: string | null;     // YYYY-MM-DD，不能用上传时间替代
  categoryId: string | null;
  tagIds: string[];
  source: "screenshot" | "manual";
  reviewStatus: "confirmed" | "needs_attention";
  reportedHoldingPnl: DecimalString | null;
  reportedDailyPnl: DecimalString | null;
  reportedPnlCurrency: string | null;
  reportedPnlDate: string | null;
};
type Snapshot = {
  schemaVersion: 1;
  id: string;
  createdAt: string;          // 导入创建时间，仅作记录
  coverage: "partial_or_unknown";
  accounts: { id: string; alias: string }[];
  categories: { id: string; name: string }[];
  tags: { id: string; name: string }[];
  holdings: ConfirmedHolding[];
};
```

持有/当日收益仅保留定义明确的金额；无法确认币种/日期时显示未提供，不替换为资产币种/日期。截图提供的百分比可在会话核对页查看，首版不持久保存或当作系统计算指标。

规则：

- 金额用十进制精确计算或整数缩放方案，禁止直接用浮点累加作为账面结果。序列化为字符串；小数位上限 8，金额绝对值上限 10^15，超界拒绝并提示核对。
- 首版币种白名单 CNY/HKD/USD/EUR/JPY/GBP；不能确定的符号设 null，其他币种保留待处理，不混入合计。扩展币种通过版本化配置实现。
- 金额、币种、名称或日期未确认时保留 needs_attention；用户可确认日期未知，但页面必须显示未知日期。名称、币种、金额不完整的行永远不入合计。
- 收录行必须 confirmed、金额非负、币种受支持。负数持仓标为首版不支持；收益负数正常。
- 同一币种下按当前筛选有效行求和；未分类进入单独类别。百分比展示舍入不反写原金额，尾差说明，不强行改金额凑 100%。
- 混合日期统计可以显示，但必须给日期集合/范围和警示；未知日期单列。无有效金额时显示“暂无可计算数据”。
- 不生成跨币种净资产、历史收益率、收益曲线或投资指令。

## 5. 状态与持久化

### 5.1 状态转换

`idle → validating → recognizing → reviewing → preview → applied`。

任一失败/取消回到可恢复状态，旧快照不变。识别结果只进入草稿；只有用户确认应用才更换内存快照。用户可明确选择保留待补行：只保留已核对字段，其余候选置 null；名称尚未确认时使用空字符串并标为 needs_attention。待补行随已应用快照保存、导出、恢复，在看板可补录，始终排除计算；不携带截图或原文。整批尚未应用的 OCR 草稿不进入存储。启用本机保存时，先在事务中写入新快照及布局，事务成功后切换已保存状态；写入失败允许用户明确选择仅在会话中应用，不能自动覆盖旧持久快照。

### 5.2 存储选择

- 默认会话内存模式。不写资产到 localStorage、sessionStorage、Cache Storage 或 IndexedDB。
- 用户主动开启“在此浏览器保存”后，IndexedDB 存当前快照和配置，无历史序列、原图或 OCR 全文。
- 自动持久更新仅适用于用户确认应用的快照（含明确保留的待补行）和显式布局修改；尚未应用的 OCR 草稿不持久化。
- 关闭保存时提供“关闭并清除已保存数据”与“取消”，避免旧数据残留却显示已关闭。
- 清除业务数据删除该应用数据库并清空内存与对象 URL；保留的静态 HTTP 缓存不能含业务数据。不影响用户下载的备份文件。
- 应用提供查看保存状态、导出和清除入口；无痕模式、配额和浏览器策略导致的差异均以操作实际结果为准。

### 5.3 导入导出

完整 JSON 格式含 `formatId`、`schemaVersion`、`exportedAt`、`snapshot`、`layout`。导出前提示“包含个人资产信息，文件未加密”。不自动包含截图、原文或本机路径。首版不实现自制加密协议；加密备份另行设计。

导入文件不超过 5 MiB、1000 条持仓，字符串字段设置长度上限，标签数与分类数有上限，拒绝重复 ID、孤立引用、非法日期/金额、未知版本和未知执行/URL 字段。先校验到新对象，预览后在一个事务内替换；JSON 解析不意味着通过校验。不使用不安全的深层对象合并，拒绝原型相关键。

仅布局导出采用单独格式 `local-portfolio-layout`：只允许固定卡片 ID、顺序、显隐、主题、密度和金额遮罩；不含筛选目标、自定义名称、标签、资产和账户信息。跨设备导入完整 JSON 后仍需用户选择是否持久保存。

迁移仅支持明确实现的旧 schema → 新 schema，先内存验证再事务提交；失败保留原数据并允许导出。不支持降级读取较新 schema。

## 6. DIY 配置模型

布局：固定卡片 ID 列表、显隐、顺序、主题枚举、密度枚举、金额遮罩开关。配置不含 HTML、CSS、脚本、远程地址或自定义公式。

账户、分类、标签属于业务数据；删除被引用项时要求替换映射或归为未分类，不连带删除资产。拖动提供键盘及上下移动替代操作，移动端按顺序单列排列。过滤改变分母时始终展示当前范围；数据异常提示不受卡片隐藏影响。

组件只使用转义文本渲染用户输入，颜色采用内置令牌。导入配置只能引用已知卡片，重复/未知 ID 拒绝或显式提示，不能隐式创建组件。

## 7. 隐私与安全控制

### 7.1 威胁范围

重点控制误上传、第三方脚本、用户文本注入、恶意恢复文件、超大图片、持久存储泄漏和错误打包。无法保证已受控设备、恶意浏览器扩展、操作系统交换文件或被篡改站点下的数据安全；隐私文案不能承诺绝对安全。

### 7.2 网络边界

静态模型/Worker/WASM/字体全部同源固定路径；不加载远程字体、统计、广告或第三方错误收集。无业务 POST、WebSocket、Beacon、表单提交或持仓相关 GET 查询。不能只凭请求方法判断安全，GET 路径也可能泄露数据。

建议安全策略起点：`default-src 'none'`、`script-src 'self'`、`style-src 'self'`、`img-src 'self' blob:`、`font-src 'self'`、`worker-src 'self'`、`connect-src 'self'`、`object-src 'none'`、`base-uri 'none'`、`form-action 'none'`、`frame-ancestors 'none'`。引擎若需要 WASM 编译权限，按目标浏览器最小放行并测试；不以广泛 `unsafe-eval` 解决兼容问题。避免内联脚本和动态 Blob Worker。

`connect-src 'self'` 仍可能允许向同源泄露，不能当作隐私证明。加载器只允许构建清单中的固定静态资源；生产代码禁用其余网络出口，且通过完整网络验收核实。外部帮助链接不携带状态参数，设置不发送 referrer；托管层配置 HTTPS、nosniff 和合适的缓存策略。

### 7.3 发布与依赖

依赖锁定并审查许可证，模型单独核查再分发许可；构建固定资产清单及校验值。静态应用仍有供应链风险，禁止运行时加载最新第三方脚本。更新时提供清晰版本号和数据格式兼容说明。

错误提示用阶段码和安全描述，不输出截图内容、金额、名称或完整文件名。测试失败截图也使用合成数据。用户主动提交问题时先提醒脱敏，系统不自动附加本地诊断包。

## 8. 验证矩阵与发布门槛

所有测试基于合成数据；不得读取个人版真实资产作为预期结果。

| 范围 | 验收内容 |
| --- | --- |
| 领域单元测试 | 单位/小数/负号/零/缺失、多币种、筛选分母、混合日期、重复候选、收益字段隔离 |
| OCR 评测 | 至少 30 张合成图，分别统计字段原始识别率、冲突检出、人工修改量；列示失败样本 |
| OCR 发布阈值 | 选定支持版式的金额和币种精确匹配率建议 ≥95%；以人工标注分母计算，不剔除识别失败样本；不达标收窄支持范围并重测 |
| 隐私网络 | 全新浏览器从加载、选图、识别、编辑、保存、导出到清除，记录全部请求，检查 URL/header/body/WebSocket/Beacon；合成敏感标记外发数为零 |
| 隐私存储 | 操作后检查所有站点存储；会话模式无业务记录；持久模式仅白名单字段；不含原图、OCR 全文或文件名 |
| 故障恢复 | Worker 取消/崩溃、超时、解码失败、配额不足、坏 JSON、较新版本；旧快照及布局不受损 |
| DIY | 排序显隐、恢复默认、类别删除、配置导入；仅布局导出无业务字段 |
| 安全 | 注入字符串作为纯文本、原型键/未知字段拒绝、资源上限、CSP 生效、第三方请求为零 |
| 浏览器/UI | 目标 Chrome/Edge/Firefox/Safari 与 Android Chrome/iOS Safari 实测；360/768/1280 宽度、键盘、读屏标签、错误提示；未测平台明确列为未验证 |
| 性能 | 记录设备、浏览器、模型大小、首次加载/识别耗时与峰值内存；建议暖启动单张典型图 P95 ≤15 秒桌面/≤30 秒移动端，作为待验证目标 |

合成标记扫描只是隐私证据之一，须结合网络白名单、存储白名单和代码审查；不能用“没有找到某串文字”证明所有数据都未泄露。

手动录入、确认快照计算与持久化正确性是硬门槛。OCR/性能目标不能在未测设备上宣传达标。若移动端不达标，明确限制首发支持设备，不能自动回退到云端识别。
