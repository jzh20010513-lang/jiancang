# Checkup Implementation Plan

> **For agentic workers:** Use TDD and bounded parallel work; root integrates and independent reviewer checks the feature. User authorized implementation in this chat.

**Goal:** 从持仓整理升级为用户目标驱动的体检、核对建议与快照对照。
**Architecture:** 新增纯函数checkup模块、v2备份兼容层、独立体检视图，与现有截图导入保持解耦。
**Tech Stack:** 原生ES模块、BigInt十进制、已有Vite/IndexedDB/Playwright，不新增联网依赖。
**Spec:** docs/specs/CHECKUP.md。

## Global Constraints
本地处理、不发布、不接触个人版。完整备份包含个人目标；纯布局不包含。金额建议只作目标差距展示，非买卖指令。体检不受图表筛选影响。

## Review Focus
未知分类和未知流动性不能误报达标；新旧导入范围不同不能冒充收益；零值目标需保留；同名不能自动确认同一资产；目标保存失败需保留旧值。
