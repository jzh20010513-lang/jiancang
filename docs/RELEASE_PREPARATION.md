# 开源发布准备

当前阶段：本地源码审阅候选，尚未上传或部署。所有者已于2026-10-29确认本轮功能验收并选择 MIT。

## 新电脑启动

需要 Node.js 22.12+ 或24+；在项目目录运行：

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
npm.cmd run preview
```

访问终端显示的 `http://127.0.0.1:4318`，不能双击 HTML。首次安装需联网下载 npm 依赖；构建不自动采集行情。OCR 模型由本站提供，截图不发送到服务端。运行测试需本机 Microsoft Edge，普通使用无需安装 Playwright 浏览器。

默认仅本次会话：已有持仓先导出备份再刷新。可主动选择保存到本浏览器；没有云同步。识别结果要逐行核对，分类候选要确认；用户自己保管截图和备份，反馈只用脱敏复现。

## 三类发布物

1. 源码包：用 Git 当前已审查提交生成归档，保留应用 LICENSE、第三方说明、依赖锁文件、源码、合成测试和文档；不带 .git 历史、node_modules、dist、public/vendor、public 行情快照、artifacts、截图和备份。
2. 静态运行包：包含 OCR/WASM/模型，需同时保留第三方声明。还未完成全部嵌入原生组件的许可复核，因此本轮不作为可公开分发的已批准产物。
3. 公众运营网址：还需解决行情来源展示/缓存/再分发条件。腾讯/Cboe 请求能够成功不等于许可。禁止把本机已有真实行情缓存直接复制到公开站点。

第一类中的采集脚本是源码功能，不附带对数据的使用许可。建立公众服务之前应接入具有适用授权的数据，或保持行情不可用；不编造指标。数据授权和源配置变更后需重验行情日期、降级和隐私边界。

## 本轮检查范围

- 当前源码与可达 Git 历史：文件名、文本凭据特征、作者邮箱、二进制/链接条目；只输出计数，不输出疑似秘密。
- 源码审阅 ZIP：只允许审查的 Git 条目，不直接压缩工作目录；核对内容、散列、禁止目录、真实行情缓存和模型二进制。
- 从独立导出目录执行干净依赖安装、测试、构建和本地页面检查；验证不依赖本机未跟踪行情文件。
- 未访问个人版或其 private/rich-state，无法据此声称逐值比对了用户全部真实数据。模式扫描通过不构成不存在任何敏感信息的数学保证。
