# 基金板块选择扩展审阅

此前将“可选板块”和“已接入行情的三项ETF”绑定，导致美股科技等合理的用户分类无法选择。本轮将分类目录与行情目录分开。

## 使用方式

导入或编辑持仓后，可查看名称/代码的明确关键词候选；候选需要用户应用并确认。在首页“管理板块关联”逐项编辑，现有22个内置分类，包含美股科技、港股科技、A股科技、人工智能、软件与云计算、互联网、医药与生物科技、全球股票等。

海外/全球类名称优先展示海外选项，但“全球/QDII”不自动等于美股科技，“纳斯达克100”不自动等于纯科技。用户可以根据产品说明或自己的已知信息选择美股科技。此功能不是完整基金分类数据库，没有联网查询用户持仓。

找不到合适分类时，在下方补充自定义名称；每个1至40字，内置与自定义合计最多3项。确认后的分类生成关联产品汇总，完整备份保存及恢复分类。搜索始终保留已选项，取消不改变正式数据。编辑分类不滚动上次快照。

## 行情覆盖

既有三项ETF公共数据源与严格白名单不变，没有因新增分类而加入任何外部请求。分类没有专属行情时，首页显示“已归类，专属行情尚未接入”，不生成技术/相对表现分数，也不将沪深300或纳指100当成美股科技板块的真实收益。已有参考市场功能仍可独立设置市场背景。

自定义分类只作文本标签；不接入URL、脚本或远程配置，不代表真实底层行业权重。持仓、截图、分类和基金名称继续留在浏览器本地。

## 验证

198/198单元测试与构建通过。扩展板块/自定义备份恢复浏览器测试、原有板块流程、导入分类流程、360/768/1280宽度及完整OCR/备份/网络隐私回归通过。测试使用虚构持仓，没有复制用户截图、基金持仓或真实金额。静态审计25文件，凭据特征命中0。

独立审查修复：应用候选时与现有自定义名称合计超限、未配对UTF-16字符可通过备份校验却导致页面编码崩溃。针对失败用例修复并复核，相关28项纯测试通过。

复现：`npm.cmd run check`，`node tests/sector-choices-browser.mjs`。旧浏览器测试可通过PowerShell设置 `$env:BASE_URL='http://127.0.0.1:4320'` 指定本机服务。当前仅本地审阅，未上传、部署或修改个人版。
