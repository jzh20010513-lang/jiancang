# 公开静态网页

已发布地址：[https://jiancang-jzh20010513.jzh20010513.chatgpt.site](https://jiancang-jzh20010513.jzh20010513.chatgpt.site)。Sites 版本1；公开访问，未启用行情中转。

公开构建入口：`npm.cmd run build:public`，输出目录 `out/`。

- 本地OCR、截图核对、资产分布、自定义分类、个人标准体检与备份恢复保留。
- 只复制 favicon、固定安全响应头和本站 OCR 资源；生成不含价格点的市场/板块数据包。不复制任何 public/ 中的其他文件，不读写本机已采集数据。
- 构建常量启用公开模式：不请求 `/api/market-quotes`，不提供盘中行情中转。页面明确提示行情尚未接入，不推断走势、资金或情绪。
- 原本的 `npm.cmd run build` 与本机预览不改变，真实持仓只由用户在浏览器操作；网站部署源码不含原图、OCR原文或持仓备份。
- WASM与模型从同站点加载。固定运行文件的第三方声明汇总在 `/vendor/THIRD_PARTY.txt`，包括 IJG 致谢及 licenses/native/ 下的原文。来源与散列见 sources.json。

## 发布配置

Sites 使用隔离的网站源码目录，静态入口为 `out/`，不部署 Node.js 本地预览服务。站点ID只写入该目录 `.openai/hosting.json`，部署凭据不写入源码、文件、日志或 Git 配置。用户个人版与本地持仓不参与构建。

GitHub 是公开源码仓库；Sites 保存对应的已推送网站源码和构建版本，两者独立。网站有新的公开部署授权，历史报告中的“尚未部署”是当时状态。

## 本轮验证

243项单元测试、常规与公开构建通过。公开构建浏览器验证无盘中报价请求、空行情包、声明可访问及390/768/1280布局；实际合成截图OCR、修改后重核和备份恢复通过。该结果不代替真实平台OCR准确率或行情授权。

用户默认仅本次会话，刷新前先导出备份。网站平台可能记录普通访问日志；浏览器存储及备份未加密。

线上补验：本地OCR真实执行的合成图流程通过。原本仅针对本机服务的接口读取测试在托管平台遇到403，严格“所有请求均为GET”假设也与Cloudflare安全验证POST不符；不把这两组原测试称为通过。新增托管测试使用正常浏览器资源请求，单独记录同源Cloudflare验证路径；不解析或认证平台不透明验证载荷，隐私边界详见PRIVACY.md。
