# 目标保存无反馈修复

目标比例需要“类别名=百分比”的结构化输入；自然语言会触发校验。原来失败只在顶部显示通用提示，用户从页面底部保存时看不到，误以为按钮失效。

现在格式、比例范围和本机保存失败都会在保存按钮附近显示具体错误，自动滚入视野并聚焦可访问的警告区；草稿保留，不替换旧目标。增加“保持当前配比，不设目标比例”操作：明确清空配置目标、不检查配置偏离，保留其他标准，不修改持仓，也不把未知分类推断成目标比例。
