# 0.2 持仓体检 · 本地审阅说明

完成日期：2026-10-27。范围：个人目标对照、可解释持仓体检与一个上次导入快照。本轮基于独立工程基线 bec7f21，未上传或部署。

## 先体验什么

打开 `http://127.0.0.1:4318`，点击“体验虚构示例”。首屏先列检查事项：为什么出现、依据来自哪里、下一步如何核对。进入“目标与体检”修改目标后，体检结果会随之改变。

- 配置对照：每币种分别比较类别目标与当前比例，展示百分点偏离和目标金额差距。
- 集中度：指明涉及的资产或用户确认分组、当前比例、自定上限；同名和同代码不自动确认底层敞口。
- 用钱安排：只把用户标注当前可用的金额计作可用；未知、受限、预计解锁不冒充当前现金。日期不一致/较旧时限制结论。
- 信息缺口：未确认持仓、缺分类、重复代码候选等先提示核对，不自动生成统一配置或健康分。
- 快照对照：真实导入后保留一个上次快照，分币种显示金额变化；导入覆盖可能不同，差额不代表收益。编辑当前持仓不滚动基线。

“我的用途”仅作为用户的计划说明，不推断风险承受能力。偏离阈值5个百分点是明确显示且可修改的表单初值，不是市场标准。配置目标可以留空，只检查用户选择的项目。

## 隐私与数据兼容

目标、流动性和历史快照同样默认只在本次会话。主动开启本机保存后才写入 IndexedDB。完整v2备份包含它们；纯布局不包含。v1备份仍可恢复，恢复后不继承现存目标或伪造目标。

演示持仓和目标分别记录来源。首次真实导入不会套用未确认的示例目标；用户在示例体验中明确保存的个人目标可以保留，演示持仓始终不充当真实历史。无持仓时也可先设置、保存和导出目标。
