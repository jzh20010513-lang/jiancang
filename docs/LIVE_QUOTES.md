# 本地公共指数行情

仅供本机审阅。固定请求腾讯公共行情 `https://qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000300`，覆盖上证综指、深证成指、创业板指、沪深300。所有用户使用同一公共请求；无用户代码、URL、请求体或持仓输入。持仓、截图及 OCR 内容留在浏览器本地；行情服务不接收这些内容，不使用数据库或磁盘缓存。

界面每60秒刷新。服务只在内存缓存30秒，合并并发请求。公共源未提供可核实的延迟保证，界面只可称“最新观测/延迟未知”，不能承诺实时成交行情。必须显示来源观测时间及实际获取时间；休市、节假日或失败时不能把旧行情称为今天的实时行情。源时间超过5分钟或在未来，状态为旧观测。失败后保留原价格及原观测时间，并明确标记不可用。首次失败显示空值，不生成价格。

## 接口契约

`createQuoteService({fetcher?, now?}).getQuotes()` 返回严格结构：

```json
{"schemaVersion":1,"mode":"live-public","fetchedAt":"2026-10-27T07:00:00.000Z","records":[{"id":"sh000001","price":3300,"previousClose":3000,"changePercent":10,"asOf":"2026-10-27T07:00:00.000Z","status":"available","error":null}]}
```

此示例仅展示字段且价格为虚构；实际数组恰好包含白名单四个指数各一次。所有日期均为规范 UTC ISO 字符串（毫秒三位、Z后缀）。源第30字段的北京时间 `YYYYMMDDHHmmss` 经日历合法性检查后转UTC；涨跌幅从价格与昨收计算，不信任源百分比字段。不可用记录的四个观测字段可以全为null，或者保留上次有效值。可用记录必须全部有效。`error` 在可用时为null，在不可用时为固定脱敏说明。

`validateLiveQuotes(payload)` 返回boolean，拒绝额外字段、重复或未知指数、非有限/非正价格、无效日期、与价格不符的涨跌幅。`quoteState(record,nowISO)` 返回 `latest`、`stale`、`unavailable`；`latest`仅表示有效源观测距当前不超过5分钟，不表示源保证实时。

默认使用固定参数 `execFile` 调用curl，不经shell执行，不读取curl配置文件，不跟随重定向；HTTPS限定，连接5秒、总请求10秒、子进程11秒、响应500000字节上限。响应使用GB18030解码，只解析固定赋值语法，绝不eval。任一指数数据无效则整次刷新失败，以免混合看似完整的新旧批次。错误不回传底层网络日志。

本地服务器提供 `GET/HEAD /api/market-quotes`，拒绝query及用户请求体，不提供跨站访问许可，不把其他路由转发到源站。前端失败应保留上次数据并标记失败，静态/导出页面无法访问该接口时应诚实显示不可用。

数据服务条款、再分发授权及商业使用权限尚未核实。本实现不构成公开发布授权；发布前应确认授权并改用适合用途的许可数据源。
