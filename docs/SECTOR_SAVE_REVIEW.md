# 板块选择保存修复

原流程在选择板块后还要求逐只勾选“我已核对”；没有勾选也可保存，首页因此仍显示关联尚未核对，用户无法理解为什么选择没有生效。

现在管理页顶部、底部提供“确认并保存所有已选板块”。用户明确点击后统一确认内置及自定义选择，并返回首页显示观察卡。未选择的持仓保留待设置状态；也可单独确认“无合适参考”。选择、推荐草稿、导入备份本身不触发确认。已有未确认选择的空看板会提示检查并确认已选板块。

分类确认不替代持仓金额、币种或日期核对，也不改变历史快照。金额与币种未核对时，板块仍可显示，关联金额不计入统计。没有专属行情的分类仍仅显示分类，不生成技术指标。

应用后通知区分仅本次会话与保存于此浏览器；本机写入失败后选择仅会话应用时，保留失败及旧备份提示，不显示保存成功。

验证：200/200单元测试及生产构建通过；批量确认、扩展分类、原板块流程、通用导入/备份/存储失败浏览器回归通过。管理页360/768/1280宽度检查通过。测试只用虚构持仓。修复经独立代码复核，未上传、部署或修改个人版，真实截图和持仓未写入仓库。

复现：`npm.cmd run check`、`node tests/sector-confirmation-browser.mjs`。其他浏览器回归可设置 `BASE_URL=http://127.0.0.1:4320`。
