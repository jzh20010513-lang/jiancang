# 个人板块配置建议审阅

在“目标与体检→设置我的目标”填写可接受亏损幅度、预计用钱时间、单板块配置上限，保存后首页板块卡片即时更新。均可留空，不按用途或基金名称推断风险偏好。设置随完整备份保存，纯布局不包含；旧备份继续可用。

卡片先显示个人关联占比和一条优先建议，详细依据折叠。顺序为：可计算数据不足、自定板块超限、近期用钱安排、亏损承受意愿与有效代理历史回撤、其他已设置个人规则、技术弱势、按配置观察。分类无专属行情也可计算占比和对照上限，不再只有“尚未接入”的提示。

占比以同币种全部已确认非负持仓为分母，不跨币种换算。不完整持仓和不同日期会提示结论限制。多板块关联可能重叠，关联产品金额不代表基金真实底层行业敞口。超过上限提示检查重复投资范围并评估是否回到自己的目标，不生成交易金额或订单。

用钱日期在未来365日检查窗口内提示核对需要金额、到账时间及资金覆盖；已过日期提示更新安排。该窗口是公开的产品检查规则，不是推荐投资期限。全局日期不覆盖各币种已有资金安排。

亏损幅度用于显示同币种已确认总额的假设波动金额。若有效ETF代理的最近20收盘样本回撤超过自定幅度，会提示复核承受意愿；明确不是用户组合回撤或未来预测。设为0时提示核实产品本金损失风险。不保证止损、不承诺保本。

行情缺失、过期或刷新失败，不驱动当前方向判断。情绪仍无可核验来源，明确显示证据不足；本轮未扩展行情数据源。无行情的分类仍不能提供专属技术分析。金额遮罩同时隐藏个人建议标题、内容、比例和压力情景金额。
