# 本机真实截图验收清单

这份清单供使用者自己操作，开发自动测试不等于真实支付宝截图验收。请勿把真实截图、备份或 OCR 全文提交到仓库或问题反馈中。

## 开始前
- [ ] 如果已有持仓，先在“数据与备份”导出完整备份，再刷新审阅页面。默认会话模式下刷新会清空当前内容。
- [ ] 在独立看板选择一张自己保管的清晰截图；名称被省略时，到原平台核对全名。无需向开发者发送真实数据。

## 按使用顺序检查
- [ ] 导入：候选数量与截图相符，没有把占比、收益或界面标签当作资产名称和金额。缺失字段可以留空，不强行生成历史收益率。
- [ ] 核对：逐项对照名称原图片段、金额和币种；必要时纠正名称，特别是 A/C 份额。没有定位片段时对照完整截图或原平台。
- [ ] 确认：未核对或不完整行不计入合计；如要保留，明确选择“作为待补行保留”。确认后修改字段，需要重新核对该行。
- [ ] 分类：为基金选择正确板块/市场参考并确认，允许多个或自定义分类。基金名称或代码修改后，原关联退回待核对，须重新确认。
- [ ] 看板：按币种核对总额、板块关联产品金额与占比。关联产品金额不等于底层行业敞口，多板块占比不能相加。
- [ ] 建议：填入自己的亏损承受意愿、用钱时间和板块上限，观察建议是否随标准改变。缺失或过期的行情应明确提示；代理指数表现不是基金实际收益。
- [ ] 备份：导出完整备份，核对文件确实下载成功。可先在另一个独立浏览器会话恢复，验证持仓、分类和个人标准一致；无需删除唯一的数据副本。

## 反馈方式
只记录哪一步、预期结果、实际结果。用虚构名称和金额重现；如需截图，先裁去真实持仓、账户、姓名和金额。测试人员不应把合成用例通过标记成已完成本清单。
