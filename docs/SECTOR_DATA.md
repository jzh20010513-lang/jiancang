# 板块公共日线（本机审阅）

板块目录独立于六项市场目录，只包含半导体ETF（sh512480）、医疗ETF（sh512170）、新能源车ETF（sh515030），参照沪深300。ETF价格只作为板块走势代理：存在费用、跟踪误差、成分与行业定义差异，不能代表所有同类资产，不推断用户持仓、板块敞口、情绪、资金流或交易建议。

公共源为目录内固定的腾讯财经ETF日线地址，使用前复权 OHLC 和提供方成交量；成交量缺失保持 `null`，不填零，也不推断其单位。未独立确认数据使用、缓存、再分发授权；本功能仅供本机审阅，未经确认不向公开站点分发快照。

手动刷新入口：`node scripts/refresh-sectors.mjs`，不接受参数，只请求三条固定地址。每次请求最长20秒、响应上限1,000,000字节；只解析JSON或惰性变量赋值包装，不执行脚本。北京时间16:00前剔除当日日线，之后也只接纳不晚于当日的数据，节假日不补点。旧快照通过严格校验后，可在刷新失败时保留原始日期与数值；失败提示经过清理，不保存远程错误正文。

构建入口：`node scripts/prepare-sectors.mjs`。构建不联网，检查字节数与严格白名单结构。文件缺失生成三项明确不可用记录；结构无效直接失败，不覆盖原文件。`public/sector-data.json` 通过临时文件原子替换，保持Git忽略，不提交源码；本机审阅的dist会包含清洗后的公共快照，公开部署前须另行确认数据授权及打包策略。

结构：`{schemaVersion:1, mode:'public-snapshot', generatedAt:UTC ISO时间, records:[{id, points:[{date,open,high,low,close,volume}],source:{label,url},status,error}]}`。固定三项且不可重复，每项最多300根完整日线；日期必须真实、严格递增、无未来值；OHLC为有限正数且高低区间一致，成交量为有限非负数或null。拒绝未知字段、任意源地址、getter、额外目录项与不一致可用状态。快照时间是抓取时间，最后数据日期以日线自身日期为准。
