# 见仓 · 本地持仓看板

**[在线使用见仓](https://jiancang-jzh20010513.jzh20010513.chatgpt.site)** · 公开试用版保留本地OCR、资产整理、目标体检与备份，行情暂未接入。

把持仓截图整理成自己的资产看板，了解持仓分布、关联板块和需要优先检查的问题。

见仓是一款本地优先的网页工具：**截图在浏览器内识别，持仓由你核对，数据由你自己保管。** 无需注册，不接入云端持仓数据库或云端 OCR。

应用自有源码使用 [MIT License](LICENSE)，欢迎使用、修改和 DIY。第三方组件、模型与行情数据各自遵守原有条件，见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 可以做什么

- **导入截图**：支持 PNG、JPEG、WebP，多图导入、裁剪、旋转、本地 OCR、取消识别和手动补录。
- **核对持仓**：检查名称、金额、币种和 A/C 份额；能唯一定位时显示名称原图片段。缺失信息可以保留为待补行，不计入统计。
- **查看资产分布**：按币种统计金额，查看类别、账户与集中度；支持搜索、标签、关注及金额遮罩。
- **自定义板块**：提供22个常用分类、名称/有限代码候选及自定义分类，由用户确认关联。修改基金名称或代码后，需要重新核对原关联。
- **设置个人标准**：填写自己的目标比例、集中度上限、可接受亏损意愿和用钱安排，查看可解释的核对建议。
- **观察市场背景**：有适用数据时展示趋势、动量、量能、相对大盘和波动背景；缺失、过期或失败会提示，不补造指标。
- **自己保管数据**：默认仅本次会话；可主动开启浏览器保存，导出/恢复完整备份，或单独导出不含持仓的布局。

## 快速开始

### 环境

- Node.js **22.12+ 或24+**，以及随附的 npm。
- 支持 WebAssembly、Web Worker 和 Canvas 的现代浏览器。目前主要在 **Windows + Microsoft Edge** 验证。
- 第一次安装需要联网下载依赖；首次识别要加载本站提供的 OCR 程序与模型。

### 安装与启动

从仓库的 **Code → Download ZIP** 下载源码并解压，在解压后的项目目录打开终端。

Windows PowerShell：

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
npm.cmd run preview
```

macOS / Linux 使用对应命令：

```sh
npm ci --ignore-scripts
npm run build
npm run preview
```

打开终端显示的地址，默认是 **http://127.0.0.1:4318**。服务仅监听本机；不要直接双击 HTML。macOS、Linux、Safari、Firefox和真实移动设备尚未完成完整验收。

Windows 用户完成首次构建后，也可以双击 `打开审阅版.cmd` 启动。端口被占用时，先检查是否已有本项目服务，不要关闭未知进程。

开发模式：

```powershell
npm.cmd run dev
```

## 第一次使用

1. 点击“体验虚构示例”了解看板，或选择自己的持仓截图。
2. 裁去不需要的姓名、账号等区域，开始本地识别。
3. 对照原图逐行核对名称、份额类别、持仓金额和币种，再勾选确认。截图省略的全名需到原平台查看，系统不会猜补。
4. 预览并确认整组替换。不能确认的候选可明确保留为待补行，暂不计入统计。
5. 确认每只基金对应的板块和参考市场；分类是整理标签，不等于基金实际行业持仓。
6. 在“目标与体检”填写自己的标准，查看提示的依据和下一步核对事项。
7. 在“数据与备份”导出备份；如需刷新后保留，也可主动开启此浏览器保存。

**默认会话模式下刷新或关闭页面可能丢失当前数据，请先导出备份。** 完整备份和浏览器存储均未加密，金额遮罩不等于加密。跨设备使用可以在新设备重新导入，或手动恢复自己保管的备份。

## 市场数据与建议的边界

| 功能 | 当前行为 |
| --- | --- |
| 新下载源码的历史行情 | 仓库不包含行情快照；没有数据时显示不可用，不生成虚构曲线 |
| 本机当天报价 | 本机预览服务包含四项 A 股指数的固定公共请求；页面可见时每60秒读取，显示源时间，延迟未知 |
| 美股/港股历史观察 | 有适用日线或周线数据时展示；不代表已支持海外盘中实时报价 |
| 三面观察 | 技术、市场和波动背景分别解释；缺少适用情绪证据时明确保持未知，不打统一分 |
| 个性化提示 | 对照用户自定标准及已核对持仓，提出核对清单，不代替投资判断或执行交易 |

行情访问成功不等于获得公开展示或再分发授权。**应用源码开源，不代表腾讯/Cboe 数据随之开源。** 本机采集脚本不附带数据使用许可；公开运营网站前须取得适用授权或换用授权数据源，详见[发布准备](docs/RELEASE_PREPARATION.md)。

分类关联的产品占比不是底层行业敞口，多个板块可能重叠，不能相加。指数/ETF观察代理不是你的基金实时净值或持仓收益。VIX仅作美国宽基波动背景，不充当所有市场或基金的情绪分数。

## 识别准确率与限制

OCR用于生成候选，**必须人工核对**。目前没有任何银行、券商或支付宝的官方认证。

既有36张虚构合成截图共108条持仓的严格测试结果：名称正确91/108，金额和币种配对正确107/108，完整行正确90/108。它们是特定测试集结果，不能推算真实截图准确率；模糊、深色、遮挡、复杂多列与名称截断仍可能失败。详见 [OCR评估](docs/OCR_EVALUATION.md)和[名称核对记录](docs/NAME_REVIEW_2026-10-29.md)。

当前不提供完整基金数据库、历史收益率、自动汇率、跨币种总额、负债/杠杆统计、交易执行或云同步。数据不完整时，只显示有依据的结果。

## 隐私

- 截图、文件名、OCR全文和持仓不会由应用发送到服务器；OCR在浏览器内运行，不调用远程AI。
- 原图与OCR全文只在导入会话使用，不进入完整备份或浏览器持久化；核对后的持仓仅在主动保存后写入此浏览器。
- 完整备份含你的持仓与个人标准，请自己保管。纯布局导出不含业务数据。
- 浏览器扩展、设备安全及托管方普通访问日志不受本应用完全控制。详见 [PRIVACY.md](PRIVACY.md)。

**请勿在 Issue、PR、截图或日志中提交真实持仓、账户、姓名、金额、API Key、Token 或完整备份。** 反馈问题请用虚构数据提供复现步骤。

## 开发与验证

项目使用原生 JavaScript ES modules、Vite、Tesseract.js 和 Node.js 本机静态预览服务，没有持仓后端数据库。

| 目录 | 用途 |
| --- | --- |
| `src/` | 页面、持仓数据、OCR、分类、市场及体检规则 |
| `scripts/` | 构建资源、合成素材、公共行情采集和本机预览 |
| `tests/` | 单元测试与使用虚构数据的浏览器验证 |
| `docs/` | 产品、技术、指标边界与验证记录 |
| `licenses/` | 保留的上游模型许可文本 |
| `dist/` | 本机生成的构建产物，不提交 |
| `artifacts/` | 本机测试资料，不提交 |

```powershell
npm.cmd run check
node scripts/audit.mjs
```

浏览器测试使用本机 Microsoft Edge，需先运行构建后的预览：

```powershell
node tests/browser.mjs
node tests/name-review-browser.mjs
node tests/fund-identity-browser.mjs
```

默认连接4318；若使用其他端口，可先设置 `$env:BASE_URL='http://127.0.0.1:4320'`。完整OCR基准及素材生成方法见[OCR评估](docs/OCR_EVALUATION.md)。测试仅用合成资料，禁止引入真实持仓。
